
# DNA Sequence Analysis Using Python

## About
This is my beginner bioinformatics project built using Python.
It analyses DNA sequences and calculates basic sequence statistics.

## Features
- DNA sequence validation
- Sequence length calculation
- Nucleotide counting (A, T, G, C)
- GC content and AT content calculation
- Complement sequence
- Reverse sequence
- DNA-to-RNA transcription
- FASTA file input

## Technologies
- Python
- Visual Studio Code
- Git and GitHub

## Learning Objectives
- Practise Python programming
- Understand basic DNA sequence analysis
- Apply programming to bioinformatics
